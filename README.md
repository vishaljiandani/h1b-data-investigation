# h1b-data-investigation

The purpose of this repo is to study the H1B lottery data that was released by USCIS after a lawsuit was brought against the Department of Homeland Security under the Freedom of Information Act by Bloomberg News. More information on that can be found here -> https://github.com/BloombergGraphics/2024-h1b-immigration-data.

I started by using Pandas to tidy up the data and create fresh .csv files that I've then imported into Snowflake.

I then wrote some queries to answer a few basic questions around this data for the last 4 fiscal years.

I plan to study this data further and maybe adding a few visualizations to depict certain trends.

Happy Reading!
